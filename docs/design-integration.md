# Claude Design integration

The user supplied `AnyDesk alternatifi tasarım.zip` on 2026-10-18. The reference
contains `Opendesk.dc.html`, `support.js`, and `Opendesk Logo.dc.html`; copies are
preserved under `design-reference/` for design review.

The native Rust and Flutter interfaces adapt the supplied layout, light/dark
palette, typography, overlapping-window logo A, navigation and session panels.
IBM Plex Sans regular/semibold and IBM Plex Mono regular are bundled locally
with the SIL Open Font License. Production applications do not depend on a
font CDN or load the exported `support.js` runtime.

The reference is an interactive prototype. Its demo devices/history, chat,
incoming files, fixed latency, sample codes and timed fake connection requests
are not application data. Opendesk uses real device settings, transport events,
actual frames, progress and permissions instead. Desktop-specific advanced
controls remain available beyond the reference's preview screens.

The desktop implementation uses egui; the Android implementation uses Flutter.
The exported page's decorative browser frame and demo operating-system title
bar are adapted to the native application window. This is a functional native
implementation of the design, not a web page embedded as a mock remote session.

Desktop preview images are generated by the application renderer using
`--ui-capture PATH` and do not capture other windows or start a remote session.
